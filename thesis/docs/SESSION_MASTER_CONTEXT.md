# 🧠 SDMS THESIS - SESSION MASTER CONTEXT

## 1. BỐI CẢNH DỰ ÁN
- **Tên dự án:** Hệ thống quản lý ký túc xá thông minh (Smart Dormitory Management System - SDMS).
- **Mục tiêu hiện tại:** Hoàn thành mục **3.5 Hệ thống màn hình** trong báo cáo luận văn.

    3. Đảm bảo ngôn ngữ và phong cách trình bày chuẩn luận văn kỹ thuật.
