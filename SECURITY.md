# Security Policy

## Supported Versions

Only the latest version of SDMS Android is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of SDMS Android seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1.  **Do not** open a public issue.
2.  Send an email to `security@sdms-project.example.com` with a detailed description of the vulnerability.
3.  Include steps to reproduce the issue and any potential impact.

We will acknowledge your report within 48 hours and provide a timeline for a fix if necessary.
