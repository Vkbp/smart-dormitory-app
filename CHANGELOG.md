# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-07-16
### Added
- Comprehensive internal documentation hub.
- SQLCipher for database encryption.
- MVI Pattern for ViewModels.
- Student RFID assignment and Curfew request features.
- Admin Smart Access (Remote Unlock).

### Changed
- Refactored God Object `LoginViewModel` into specialized components.
- Standardized API response handling.

### Fixed
- MITM vulnerability (Cleartext traffic disabled).

## [1.0.0] - 2026-06-01
### Added
- Initial release with core Student and Admin features.
