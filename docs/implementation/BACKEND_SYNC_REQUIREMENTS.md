## 2. Infrastructure Requirements

### [INFRA-01] Push Notifications (FCM)
- **Status**: Critical Block
- **Requirement**: 
    - Setup Firebase Cloud Messaging (FCM) for the project.
    - Provide `google-services.json` or the Server Key/Service Account for mobile integration.
    - Implement endpoints to store/update FCM registration tokens for each user account.
    - Implement notification triggers for: Curfew request approval/rejection, Payment success, and Admin emergency alerts.

### [ACC-01] Offline Access QR Protocol
- **Status**: High Priority
- **Requirement**: 
    - Define a standardized algorithm for generating access QR codes offline (e.g., TOTP-based signature).
    - Provide the backend verification logic to ensure parity between mobile-generated offline codes and gate scanner validation.
    - Specify how the "Secret Key" will be securely shared during initial mobile setup.

## 4. Security Confirmation

### [SEC-01] Role-Based Access Control (RBAC) Verification
- **Request**: Confirm that every API endpoint validates the `role` field within the JWT payload. 
- **Rationale**: Mobile relies on `RoleGuard` for UI visibility, but backend must be the final authority to prevent role escalation on rooted devices.

### [TLS] Certificate Pinning
- **Request**: Provide the SHA-256 hashes of the SSL certificates for the production/staging servers to be hardcoded in the Mobile `Constants.kt`.
